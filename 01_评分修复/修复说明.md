# 评分逻辑修复说明（改动清单）

> 规则版本：`survey_scoring:2.0-official-rules`
> 详细论证见 [`审计报告.md`](审计报告.md)；回归数据见 [`旧新分回归对照.md`](旧新分回归对照.md)

---

## 一、改了什么

### 1. 新增 `services/sjtu_survey_pro/survey_scoring.py`（计分核心）

单文件承载全部官方规则算法，纯函数、可单测：

- `ITEM_BANK` —— 以本课题问卷**实际题干**为键的显式条目库，
  声明 `量表 / 成分·维度 / 是否反向`（共 9 个量表、约 180 条计分题 + 非计分项）。
- `classify_item()` —— 三级匹配（精确 → 归一化 → 唯一前缀模糊），
  未命中返回 `_UNKNOWN` 并累计，**不再静默丢弃**。
- 9 个计分器：`score_pss14 / score_gad7 / score_phq9 / score_psqi /
  score_ipaq / score_whoqol / score_debq / score_gsrs / score_vsi`
  + `compute_bmi`。
- 统一缺项策略：`MISSING_RATIO_INVALID = 20%`；
  每个结果含 `n_items / n_expected / n_missing / valid / warning`。
- `score_all()` / `coverage_report()` 供批量重算与覆盖率自检。

### 2. 修改 `services/sjtu_survey_pro/survey_analysis.py`

| 位置 | 改动 |
|---|---|
| 模块头 | 新增 `import survey_scoring as SC` 与 `SCORING_VERSION` |
| `analyze_survey_responses()` 第二遍 | 量表归属改用 `SC.classify_item()`（修 E6） |
| `analyze_survey_responses()` 第三遍 | 计分统一委托 `SC.SCORERS`（修 E1–E5、E7–E10），并把领域分/成分分映射进 `subscales` 以兼容原 HTML 渲染层 |
| `analyze_survey_responses()` 末尾 | 报告新增 `scoring_version` 字段 |
| `find_scale_by_title()` | 改为委托 `SC.classify_item()`；旧实现保留为 `_find_scale_by_title_legacy` |
| `_score_debq / _score_psqi / _score_ipaq / _score_whoqol` | 改为委托 `SC.*`；旧实现保留为 `*_legacy` |
| `_score_scale` | 标注「已弃用·仅供兼容」并说明缺陷 |
| `_calculate_bmi` | 改为委托 `SC.compute_bmi` |
| `MAX_SCORES`（渲染层） | `GSRS 105 → 75`、`VSI 75 → 90` |

> **兼容性**：对外函数名（`analyze_survey_responses`、`render_html_report`、
> `generate_suggestions`、`find_scale_by_title`）全部保留；返回结构新增字段而非删改，
> 历史调用方（`feedback_server.py` / `email_feedback.py` / `survey_sync_cron.py` /
> `survey_pipeline.py`）无需改动即可运行。

### 3. 新增测试与回归工具

- `tests/test_scoring.py` —— 111 项断言，覆盖反向极值、缺项、量程边界、
  分档边界、BMI 中国标准、量表识别回归。
- `regenerate_regression.py` —— 只读库重算 + 旧新分统计对照。

## 二、没有改什么（边界声明）

- **未修改任何原始答卷数据**：只读库全程 `mode=ro`；未回填、未新增列、未建新表。
- **未修改其它服务**（`diet_survey` / `exercise_survey` / `data_dashboard`）的代码。
- **未改动问卷表单本身**（如 PSQI 3 级频率选项、缺失题目）——仅在报告与本文档中披露。
- **未删除旧算法**：旧实现以 `*_legacy` 名义保留，便于对照与回溯。

## 四、遗留风险

1. **PSS-14 反向条目数**（6 vs 英文原版 7）需课题组确认中文量表定稿。
2. **PSQI 频率 3 级 → 成分分域**已做层级压缩适配，方法学需披露。
3. **GSRS / VSI / PSS-14 分档为项目自定义**，非量表官方切点。
4. **旧的 `*_score` 列未回填**：如需用新分分析，请重算写入**新列/新表**，
   保留旧列以维持可追溯性。
5. `survey_analysis.py` 中保留的 `*_legacy` 函数为死代码（仅对照用）；
   若后续版本不再需要对照，可整段删除。
