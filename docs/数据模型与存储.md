# 数据模型与存储

> 个性化饮食干预课题 — 服务器端研究系统
> 本文件逐库、逐表列出**字段 / 存放路径 / 保留策略**，并给出二期菌群数据的
> 预留存储与导入接口约定。
>
> 绝对路径以 `$APP_BASE` 表示（默认 `/opt/gutbrainaxis`），可由
> `config/app.yaml → database.*` 覆盖。

---

## 0. 总览

| 库 | 文件路径 | 归属服务 | 写入方 | 读取方 | 备份 |
|---|---|---|---|---|---|
| 问卷库 | `$APP_BASE/sjtu_survey_pro/survey_data.db` | sjtu_survey_pro | 同步 / 反馈服务 / 邮件 | 看板、控制台、报告 | ✅ 14 份 |
| 饮食库 | `$APP_BASE/diet_survey/diet_data.db` | diet_survey | Webhook / 同步 / LLM 队列 | 看板、报告 | ✅ 14 份 |
| 运动库 | `$APP_BASE/exercise_survey/exercise_data.db` | exercise_survey | 同步 cron | 看板 | ✅ 14 份 |
| 菌群库 | `$APP_BASE/microbiome/microbiome_data.db` | microbiome | 导入任务 | 研究者（导出） | ✅ 14 份 |
| 名册 | `$APP_BASE/data_dashboard/roster.json` | data_dashboard | 研究者维护 | 看板完成度统计 | ✅（配置备份） |

**通用约定**

* 引擎：SQLite（WAL 模式，`PRAGMA foreign_keys=ON`）；时区为本地时区（Asia/Shanghai）。
* 时间字段：`created_at` 默认 `datetime('now','localtime')`。
* 幂等：业务表用唯一键（`submission_id` / `(sample_id, omics_type)` 等）去重，重复导入不产生新行。
* 迁移记账：每库有 `schema_migrations(version, description, applied_at, status, message)`。
* **PII 边界**：`student_id`（学工号）作为连接键保留在业务库内；任何**对外导出**
  必须经 `tools/export_data.py --anonymize` 转为 `P###` / HMAC 哈希。

## 1. 问卷库 `survey_data.db`

### 1.1 `submissions` — 一次量表提交一行

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增主键 |
| `student_id` | TEXT NOT NULL | 学工号（连接键；导出时匿名化） |
| `submission_id` | TEXT UNIQUE | 问卷平台流水号（幂等键） |
| `name` / `email` | TEXT | 被试姓名 / 邮箱（导出时剔除或哈希） |
| `responses` | TEXT(JSON) | 逐题作答 `{题干: 作答文本}` |
| `item_scores` | TEXT(JSON) | 逐条目分值 |
| `raw_data` | TEXT(JSON) | 问卷平台原始响应（导出默认剔除） |
| `analysis` | TEXT(JSON) | 分析报告（导出默认剔除） |
| `redirect_user` / `redirect_quest` / `redirect_answer` | TEXT | 报告页跳转参数 |
| DEBQ | `debq_emotional_score`/`_mean`/`_level`，`debq_external_*`，`debq_restrained_*`，`debq_total`，`debq_interpretation` | 三亚量表分与均分（1–5）与分档 |
| GAD-7 | `gad7_score`(0–21)，`gad7_n_items`，`gad7_interpretation` | 总分/条目数/分档 |
| PHQ-9 | `phq9_score`(0–27)，`phq9_n_items`，`phq9_interpretation` | 同上 |
| PSQI | `psqi_score`(0–21)，`psqi_n_items`，`psqi_interpretation` | 7 成分之和 |
| PSS-14 | `pss14_score`(0–56)，`pss14_n_items`，`pss14_interpretation` | 含 6 条反向 |
| GSRS | `gsrs_score`(15–75)，`gsrs_n_items`，`gsrs_interpretation` | 5 子量表 |
| VSI | `vsi_score`(15–90)，`vsi_n_items`，`vsi_interpretation` | 含 1 条反向 |
| WHOQOL-BREF | `whoqol_score`，`whoqol_n_items`，`whoqol_interpretation` | 四领域 0–100 见 `analysis` |
| IPAQ-S | `ipaq_met_min_week`，`ipaq_sedentary_min`，`ipaq_interpretation` | MET-min/周 |
| BMI | `bmi_score`，`bmi_category`，`bmi_interpretation` | WHO 中国切点 |
| `submitted_at` | TEXT | 问卷提交时间 |
| `created_at` | TEXT | 入库时间 |

索引：`student_id`、`submission_id`。

### 1.2 `email_log` — 邮件发送队列与结果

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `submission_id` | TEXT FK | 关联提交 |
| `student_id` | TEXT | 收件人学号 |
| `recipient` | TEXT NOT NULL | 收件邮箱 |
| `status` | TEXT | `pending`/`sent`/`failed` |
| `attempts` | INTEGER | 重试次数 |
| `last_error` | TEXT | 最后一次错误 |
| `fallback_sent` / `fallback_to` | INTEGER / TEXT | 回退发送标记与地址 |
| `created_at` / `updated_at` | TEXT | 时间戳 |

索引：`status`、`submission_id`。

**保留策略**：随备份 14 天滚动；`email_log` 可按 `status='sent' AND created_at < -90d` 手工清理。

## 2. 饮食库 `diet_data.db`

### `submissions`

| 字段 | 说明 |
|---|---|
| `id` / `student_id` / `submission_id` / `name` / `email` | 同问卷库 |
| `responses` | 逐题作答 JSON |
| `raw_data` | 原始回调 JSON |
| `record_date` | 记录日期（`YYYY-MM-DD`） |
| `diet_description` | 当日饮食文本描述 |
| `meal_count` | 识别出的餐次数量 |
| `dietary_advice` | LLM 生成的饮食建议 |
| `fulfillment_report` | 执行情况回报 |
| `redirect_*` | 报告页跳转参数 |
| `submitted_at` / `created_at` | 时间戳 |

**衍生文件**：`diet_survey/food_nutrition.csv`、`dish_nutrition_calculated.csv`（营养素映射，随仓库发布）。

**队列落点**：`diet_survey/.llm_queue/{pending,done,failed}/*.json`
任务字段：`db_id, student_id, diet_desc, record_date, submission_id, email, created_at, attempts`。

**保留策略**：`failed/` 需人工排查后清理；`done/` 建议保留 30 天后归档。

## 4. 菌群库 `microbiome_data.db`（二期预留）

### 4.1 `omics_samples` — 样本级

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `sample_id` | TEXT NOT NULL | 样本编号（外部唯一编码） |
| `student_id` | TEXT | 学工号（连接键） |
| `sid_hash` | TEXT | 学工号 HMAC（可对外） |
| `timepoint` | TEXT | 时点（`T0`/`T1`/`T2`） |
| `sample_date` | TEXT | 采样日期 `YYYY-MM-DD` |
| `sample_type` | TEXT | `stool`/`saliva`/`blood`/`urine`/`other` |
| `omics_type` | TEXT NOT NULL | `metagenome`/`scfa`/`inflammation`/`metabolome`/`transcriptome`/`other` |
| `batch` | TEXT | 实验批次 |
| `platform` | TEXT | 测序/检测平台 |
| `notes` | TEXT | 备注 |
| `extras` | TEXT(JSON) | 未在规范列内的额外列（`allow_extra_columns`） |
| `source_file` | TEXT | 来源文件名（可追溯） |
| `created_at` | TEXT | 入库时间 |

**唯一键**：`(sample_id, omics_type)`；索引：`student_id`、`(omics_type, timepoint)`。

### 4.2 `omics_measurements` — 指标级（长表）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `sample_id` | TEXT NOT NULL | 关联样本 |
| `feature` | TEXT NOT NULL | 指标名（菌属/通路/代谢物/细胞因子） |
| `feature_type` | TEXT | 指标类别（`taxon`/`pathway`/`metabolite`/`cytokine`/`wide`…） |
| `value` | REAL | 数值 |
| `unit` | TEXT | 单位（如 `rel_abundance`、`umol_g`、`pg_mL`） |
| `method` | TEXT | 检测方法（`shotgun`/`gc`/`elisa`…） |
| `qc_flag` | TEXT | 质控标记（`pass`/`fail`/…） |
| `extras` | TEXT(JSON) | 额外列 |
| `created_at` | TEXT | 入库时间 |

**唯一键**：`(sample_id, feature, method)`；索引：`sample_id`、`feature`。

### 4.3 `omics_import_log` — 导入留痕

| 字段 | 说明 |
|---|---|
| `id` | 自增 |
| `filename` | 原文件名 |
| `sha256` | 文件摘要（**唯一键**，用于幂等去重） |
| `omics_type` | 组学类型 |
| `rows_ok` / `rows_skipped` | 成功/跳过行数 |
| `status` | `ok`/`failed`/`skipped` |
| `message` | 详情 |
| `imported_at` | 导入时间 |

### 4.4 导入接口约定

**投递**：把 CSV 放入 `microbiome.import_dir`（默认 `$APP_BASE/microbiome/import`），
由 `research-microbiome-import.timer` 每小时扫描；也可 `--file` 指定单文件。

**命名（可选）**：`<omics_type>_<batch>_<yyyymmdd>.csv`；
未按约定命名时按 `omics_type` 列或文件名关键字推断。

**长表（推荐）**

```
sample_id,student_id,timepoint,sample_date,sample_type,omics_type,feature,value,unit,method,qc_flag
S001,524072910079,T2,2026-10-01,stool,metagenome,Faecalibacterium_prausnitzii,12.4,rel_abundance,shotgun,pass
```

**宽表**（指标为列名）

```
sample_id,student_id,timepoint,sample_type,omics_type,Shannon,Chao1,acetate
S003,524072910080,T2,stool,metabolome,4.1,220.5,39.8
```

**行为**：导入成功 → 文件移入 `processed/`；失败 → `failed/`；同 sha256 重复投递自动跳过。

**保留策略**：`processed/` 建议保留 24 个月（原始数据可追溯）；DB 随备份 14 份滚动。

## 6. 备份与保留策略汇总

| 对象 | 频率 | 保留 | 实现 |
|---|---|---|---|
| 4 个库 + `/etc/research-app/env` + rclone.conf + systemd 单元 | 每日 03:00 | 14 份 | `scripts/backup.sh` + `research-rclone-backup.timer` |
| 远端副本 | 每日 | 远端策略自定 | `scripts/rclone-backup.sh`（需 `backup.remote_enabled`） |
| 服务日志 | 按天轮转 | 14 份（压缩） | `/etc/logrotate.d/research-app` |
| 菌群导入原始 CSV | 每次导入归档 | 建议 24 个月 | `import_microbiome.py` + 人工策略 |
| LLM 队列 `done/` | 持续 | 建议 30 天 | 人工/后续自动化 |

**恢复**：见 `docs/升级备份与回滚.md`。核心是解包 `backups/backup_*.tar.gz`
并覆盖回对应库文件，然后 `systemctl restart research-*`。
