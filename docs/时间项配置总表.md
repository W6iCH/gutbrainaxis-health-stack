## 一、总览

本系统**所有**影响「周期 / 时点 / 窗口 / 超时 / 冷却 / 退避 / 节流」的配置项，共 **55** 个，全部落在 `schedule.*` / `analysis.*` / `webhook.*` / `alert.*` / `selfcheck.*` / `llm.*` / `smtp.*` / `backup.*` / `survey_platforms.*.fetch_*` 命名空间内。

**「改配置即改行为」的三条落地路径**：

1. `tools/appconfig.py --render-env /etc/research-app/env` → 端口/窗口/静默等写入 systemd 环境文件；
2. `tools/appconfig.py --render-timers /etc/systemd/system` → `schedule.*` 渲染为 `<unit>.timer.d/10-schedule.conf`（`OnCalendar` / `RandomizedDelaySec` / `AccuracySec` / `Persistent`）；改后 `systemctl daemon-reload` 生效；
3. 运行期服务（LLM worker、各 sync、告警、看板）用 `services/common/lib_schedule.py` **每 30 秒重读配置**，窗口/静默判定即时生效。

控制台「**调度**」页（`admin_console`，默认 :9000）可视化查看与修改本表全部条目，写入前自动备份 `app.yaml.bak.<时间戳>`。

## 附：timer 渲染对照（由 schedule.* 计算）

| systemd timer | OnCalendar（当前配置） | 来源键 |
|---|---|---|
| `research-survey-sync.timer` | `*:0/60` | `schedule.survey_sync_minutes` |
| `research-diet-sync.timer` | `*:0/15` | `schedule.diet_sync_minutes` |
| `research-exercise-sync.timer` | `*:0/15` | `schedule.exercise_sync_minutes` |
| `research-health-monitor.timer` | `*:0/30` | `schedule.health_monitor_minutes` |
| `research-daily-report.timer` | `*-*-* 08:30:00` | `schedule.daily_report_at` |
| `research-rclone-backup.timer` | `*-*-* 03:00:00` | `schedule.backup_at` |

> 注意：`*:0/N` 表示「每小时的第 0、N、2N… 分钟触发」。`N` 必须能整除 60 才均匀（如 15/30/60）；其余值（如 7）会被 systemd 解释为整点后的第 0、7、14… 分钟，跨小时部分由 `RandomizedDelaySec` 抖动补偿。
