# 管理控制台使用手册

> 适用版本：Admin Console v6（2026-09 发布版）
> 最后更新：2026-09-16
> 前置阅读：[`安装说明.md`](./安装说明.md)

管理控制台是系统的统一运维入口，提供**配置管理**、**进程开关**、**端口映射**、**自检面板**、**审计日志**五大模块。所有写操作均有审计记录。

---

## 1. 访问方式

### 1.1 默认地址

| 场景 | 地址 |
|------|------|
| 本机访问 | `http://127.0.0.1:9000` |
| 内网访问 | `http://<内网IP>:9000` |
| 域名访问（推荐） | `https://admin.<你的域名>` |

> ⚠️ **默认仅监听 127.0.0.1 / 内网**，不要直接暴露公网。建议通过 Nginx 反向代理 + HTTPS 访问。

### 1.2 浏览器要求

- Chrome / Edge / Firefox / Safari 最新版本即可，无需安装任何插件。

## 2. 登录与安全

### 2.1 首次登录

1. 打开控制台地址，进入登录页面。
2. 输入初始密码。初始密码由安装脚本生成，存放于：

   ```text
   $INSTALL_ROOT/config/initial_password.txt   （权限 600）
   ```

3. 登录成功后，**立即修改默认密码**。

### 2.2 修改密码

路径：**登录后 → 顶部导航 → 改密**

操作步骤：

1. 点击右上角「改密」入口。
2. 输入原密码、新密码（至少 8 个字符）并确认。
3. 点击「提交」。修改成功后需重新登录。

> 💡 忘记初始密码时，可重新查看 `initial_password.txt` 文件；若是通过控制台修改后遗忘，需在服务器上重置（见故障排查文档）。

### 2.3 会话规则

- 会话使用加密 Cookie 签名，服务端重启后失效。
- 默认无会话超时；建议配合浏览器隐私模式使用。

### 2.4 危险操作确认

涉及端口变更、进程重启等关键操作时，控制台会弹出确认框，需二次确认后**才**执行。

## 3. 模块一：配置管理

### 3.1 进入路径

登录后默认首页即为**配置管理**页面，或点击左侧导航「配置管理」。

### 3.2 界面元素

| 元素 | 说明 |
|------|------|
| 配置列表 | 展示所有配置项的 Key、当前值（敏感项打码）、更新时间 |
| 编辑按钮 | 每个配置项右侧的「编辑」按钮 |
| 保存按钮 | 编辑后点击保存，需二次确认 |
| 恢复默认 | 一键恢复所有配置到安装时默认值 |

### 3.3 操作步骤（修改配置）

1. 在配置列表找到要修改的项。
2. 点击该行右侧的「编辑」按钮，进入编辑态。
3. 修改配置值。敏感字段（如密码、Token）会显示为 `••••••`，输入新值可替换。
4. 点击「保存」，弹出确认框，点击「确认保存」。
5. 页面提示「保存成功」。部分配置需重启服务生效，页面会提示。

### 3.4 支持的配置项

> ℹ️ 具体配置项以安装时生成的 `config/**/*.env` 为准，控制台会动态读取。常见配置包括：

| 配置组 | 典型项目 |
|--------|----------|
| 邮件服务 | SMTP 服务器、端口、账号、密码、发件人 |
| LLM 服务 | API 地址、API Key 列表、模型名 |
| 问卷平台 | 问卷令牌、页面大小 |
| 系统 | 监听地址、日志级别、备份开关 |

### 3.5 常见报错

| 报错 | 原因 | 处置 |
|------|------|------|
| 「配置校验失败」 | 端口/邮箱格式错误 | 按提示修改后重试 |
| 「保存失败：无权限」 | 会话已过期或非管理员 | 重新登录后重试 |
| 「需要重启服务生效」 | 该配置为运行时常量 | 保存后按提示重启服务 |

## 4. 模块二：进程开关

### 4.1 进入路径

左侧导航 → **进程开关**

### 4.2 界面元素

| 元素 | 说明 |
|------|------|
| 服务列表 | 每行一个服务，含名称、中文标签、状态 |
| 状态指示灯 | 🟢 运行中 / ⚪ 已停止 / 🟡 异常 / 🔴 失败 |
| 操作按钮 | 每个服务的「启动 / 停止 / 重启 / 禁用 / 启用」 |

### 4.3 操作步骤（重启一个服务）

1. 在服务列表中找到目标服务。
2. 点击该行右侧的「重启」按钮。
3. 弹出确认框，点击「确认重启」。
4. 等待 3–5 秒，状态指示灯应从 🟡 → 🟢。
5. 如需查看启动日志，点击「日志」按钮。

### 4.4 常见状态说明

| 状态 | 含义 | 建议操作 |
|------|------|----------|
| 🟢 运行中 | 服务正常 | 无需操作 |
| ⚪ 已停止 | 手动停止或未启动 | 点击「启动」 |
| 🟡 异常（Restarting） | 服务崩溃后重启中 | 等 10 秒观察；若反复异常，查看日志 |
| 🔴 失败（Failed） | 服务启动失败 | 点击「日志」查原因，修复后重启 |

### 4.5 操作记录

所有启停操作都会写入审计日志（模块五），包含操作人、时间、目标服务、动作和结果。

## 5. 模块三：端口映射

### 5.1 进入路径

左侧导航 → **端口映射**

### 5.2 界面元素

| 元素 | 说明 |
|------|------|
| 映射列表 | 每行一个服务，含服务名、端口号、协议、用途 |
| 状态列 | 显示端口当前状态（监听中 / 未监听 / 冲突） |
| 编辑按钮 | 修改某服务的端口号 |
| 冲突提示 | 若端口已被占用，红色标出并提示 |

### 5.3 默认端口表

具体端口分配以 [`端口与反向代理配置.md`](./端口与反向代理配置.md) 中的表格为准，控制台会读取实际配置展示。

### 5.4 操作步骤（修改端口）

1. 在映射列表中找到目标服务。
2. 点击「编辑」。
3. 输入新的端口号（1–65535）。
4. 点击「保存」。系统自动进行**端口冲突检测**：

   - ✅ 无冲突 → 生成并保存配置，提示重启服务生效。
   - ❌ 有冲突 → 保留原配置，显示冲突的服务名和端口，修改后重试。

5. 确认后，控制台自动**重新生成 Nginx 配置**并执行 `nginx -t` 校验。
6. 校验通过后自动执行 `systemctl reload nginx`，更新生效。

### 5.5 冲突检测机制

- 检测范围：当前系统上所有监听中的 TCP 端口。
- 检测规则：
  - 端口号不能与其他服务重复；
  - 若端口被无关进程占用，也会标记冲突；
  - 端口号必须为 1–65535 之间的整数。

## 6. 模块四：自检面板

### 6.1 进入路径

左侧导航 → **自检面板**

### 6.2 功能

面板自动执行以下检查，并输出 ✅ / ⚠️ / ❌ 状态：

| 检查项 | 说明 |
|--------|------|
| 服务存活 | 各 systemd 服务运行状态 |
| 端口监听 | 各服务端口是否监听 |
| 数据库 | SQLite 数据库可读、可写检查 |
| 配置完整性 | 检查是否存在未替换的占位符（`__CHANGE_ME__`、`__REPLACE_`） |
| 邮件连通性 | SMTP 服务器连接测试（可选） |
| 磁盘空间 | `/` 和 `$INSTALL_ROOT` 分区剩余空间 |

### 6.3 操作步骤

1. 进入自检面板，点击「开始自检」按钮。
2. 等待约 5–30 秒，面板逐项刷新状态。
3. 查看结果：
   - 全部 ✅ → 系统正常运行。
   - 有 ⚠️ → 查看警告详情，按提示处理。
   - 有 ❌ → 记录失败项，参考「常见故障排查」文档处理。
4. 如需导出结果，点击「复制报告」将结果复制到剪贴板。

### 6.4 自动触发

自检面板结果会被刷新到：

```text
$INSTALL_ROOT/logs/ 下的健康检查日志
```

（精确文件名以实际运行为准）

## 7. 模块五：审计日志

### 7.1 进入路径

左侧导航 → **审计日志**

### 7.2 功能

展示所有管理操作的完整记录，包括：

| 字段 | 说明 |
|------|------|
| 时间 | 操作的日期与时间 |
| 操作者 | 登录用户名或来源 IP |
| 事件类型 | 配置修改 / 进程操作 / 端口变更 / 登录等 |
| 目标 | 被操作的服务或配置项 |
| 结果 | 成功 / 失败 / 被拒绝 |
| 详情 | 变更前后的摘要信息 |

### 7.3 操作步骤

1. 进入审计日志页面，默认展示最近 200 条记录。
2. 使用筛选条件：
   - **关键词**：按事件类型或目标搜索。
   - **日期范围**：限定查询时间段。
   - **结果**：只看成功 / 失败。
3. 点击单条记录可展开查看完整详情。

### 7.4 审计日志存储

实际日志文件位于：

```text
$INSTALL_ROOT/logs/console_audit.log
```

### 7.5 安全提醒

- 配置修改、进程操作、端口变更都会**自动记录**，不可手动删除。
- 批量导出建议使用 `tail` 或 `logrotate` 归档，避免侵删。

## 8. 常见问题（FAQ）

### Q1：忘记控制台密码怎么办？

在服务器上执行：

```bash
# 查看初始化密码文件
cat $INSTALL_ROOT/config/initial_password.txt

# 如密码已被修改且遗忘，需在服务器上重置
# 具体重置方法见《常见故障排查.md》
```

### Q2：控制台打不开？

- 确认服务是否运行：`systemctl status research-admin-console`
- 确认端口是否监听：`ss -tlnp | grep 9000`
- 确认防火墙是否放行内网访问

### Q3：修改端口后 Nginx 报错？

- 查看错误信息是否为 `nginx -t` 校验失败；
- 检查新端口是否被其他进程占用；
- 若修改失败，控制台会自动**回滚**到上一次有效配置。

### Q4：服务状态显示 🟡 反复重启？

- 点击「日志」查看具体错误；
- 常见的配置缺失或依赖问题见《常见故障排查.md》。
