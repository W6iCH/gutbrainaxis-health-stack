## 5. 可复现命令

```bash
PY=~/.openclaw/workspace/.venv-diet/bin/python3

# ① 人群基线（只读原始问卷 + 权威条目库）
$PY tools/build_population_stats.py                    # 生成 population_stats.default.json
$PY tools/build_population_stats.py --dry-run          # 只看摘要

# ② 统一配置校验
$PY tools/appconfig.py --config config/app.yaml.example --check
$PY tools/appconfig.py --config /etc/research-app/app.yaml --render-env /etc/research-app/env

# ③ 自检
$PY tools/selfcheck.py                                 # 全部
$PY tools/selfcheck.py --json --report logs/selfcheck.json
$PY tools/selfcheck.py --only config,paths,database

# ④ 模拟数据端到端测试（测后必须清除）
$PY tools/seed_mock_data.py  --root /tmp/gba-test --n 3 --report /tmp/seed.json
$PY tools/clear_mock_data.py --root /tmp/gba-test --report /tmp/clear.json

# ⑤ 迁移与导出
$PY tools/migrate.py     --status && $PY tools/migrate.py --plan
$PY tools/export_data.py --out /tmp/export --all --anonymize

# ⑥ 安装幂等（不改系统）
bash -n install.sh && bash install.sh --dry-run --prefix=/tmp/dryrun-gba
bash install.sh --dry-run --prefix=/tmp/dryrun-gba    # 第二次输出应完全一致
```
